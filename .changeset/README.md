# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`.

## Usage

When you make changes that need a version bump, run:

```bash
pnpm changeset
```

This will prompt you to:
1. Select the packages that changed
2. Choose the version bump type (patch/minor/major)
3. Write a summary of the changes

The changeset will be saved as a markdown file in this directory.

## Releasing

When you're ready to release, run:

```bash
pnpm changeset version
```

This will:
- Consume all changesets
- Update package versions
- Generate changelogs
- Remove the consumed changeset files

Then commit the changes and push.
